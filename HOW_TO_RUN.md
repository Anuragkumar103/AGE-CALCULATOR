# ✨ Age Calculator — Run Instructions

## Requirements
- Java 17 or later (download from https://adoptium.net if not installed)

## Compile & Run

```bash
# 1. Save AgeCalculator.java somewhere (e.g. your Desktop)

# 2. Open a terminal / command prompt in that folder

# 3. Compile:
javac AgeCalculator.java

# 4. Run:
java AgeCalculator
```

## Features
| Feature | Details |
|---------|---------|
| 🎨 Colorful animated background | Gradient blobs that pulse and rotate continuously |
| 🌙 Night / ☀️ Day mode | Toggle button in the top-right corner |
| ✨ Animated buttons | Hover glow effect on all buttons |
| 🎂 Age breakdown | Years, months, days + total days lived |
| ⏱ Live clock | Shows real-time while a result is displayed |
| 🎉 Birthday countdown | Days until your next birthday |
| 💾 Data persistence | All records auto-saved to ~/age_calculator_data.csv |
| 📋 History table | View, scroll, and delete saved records |
| 🖥 Full screen | Launches maximized automatically |

## Data Storage
All records are saved to:
  Windows:  C:\Users\<YourName>\age_calculator_data.csv
  Mac/Linux: ~/age_calculator_data.csv

The file survives app restarts — your history loads automatically each time.
